# Поставки FBO и остатки на ФФ

Сайт с поставками FBO и остатками на фулфилментах для кабинетов ИП Ероклинцев и Аванти (TESFE).
Данные с WB обновляет Claude по расписанию 2 раза в день: около 8:00 и 16:00 по Москве, и сам выкладывает их сюда.

## Что где лежит

| Папка | Что там |
|---|---|
| `docs/` | сам сайт (страница и файлы данных `data.json`, `stocks.json`) |
| `app/` | скрипты выгрузки и база остатков ФФ (`ff_snapshots.json`) |
| `uploads/ff1/` | сюда кладётся выгрузка ВМС **ФФ №1** |
| `uploads/ff2b/` | сюда — выгрузка ВМС **ФФ2Б** |
| `uploads/flakony/` | сюда — выгрузка ВМС **Флаконы** |
| `uploads/onyx/` | сюда — выгрузка ВМС **ONYX** |
| `uploads/processed/` | обработанные выгрузки (переносятся сюда сами) |

## Как загрузить новую выгрузку ВМС

1. Откройте нужную папку, например `uploads/ff2b`.
2. Нажмите **Add file → Upload files**, перетащите файл .xlsx, нажмите **Commit changes**.
3. При ближайшем обновлении сайт пересчитается сам. Временем выгрузки считается момент загрузки файла.

## Как обновить данные вручную

Вкладка **Actions** → «Обновление данных» → **Run workflow**.

## Токены WB

Хранятся в **Settings → Secrets and variables → Actions**:
- `TOKEN_EROKL` — токен кабинета ИП Ероклинцев;
- `TOKEN_AVANTI` — токен кабинета Аванти.

В файлах репозитория токенов нет.
